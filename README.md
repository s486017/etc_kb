# 📚 etc_kb

> **Etc. Knowledge Base** — 분류하기 애매한 모든 것을 위한 개인 지식 저장소

특정 카테고리에 딱 들어맞지 않는 메모, 코드 조각, 트러블슈팅 기록, 그리고 "나중에 다시 찾아볼 것 같은" 모든 것들을 한곳에 모아두는 공간입니다.
흩어진 정보를 잃어버리지 않고, 필요할 때 빠르게 다시 꺼내 쓰는 것을 목표로 합니다.

---

## ✨ 무엇을 담나요

이 저장소는 형식에 얽매이지 않습니다. 대략 아래와 같은 것들이 모입니다.

- 🛠️ **트러블슈팅** — 한 번 겪었던 에러와 해결 과정
- 💡 **스니펫 & 팁** — 자주 쓰는 명령어, 설정, 코드 조각
- 📝 **메모 & 아이디어** — 떠오른 생각, 정리하다 만 초안
- 🔖 **레퍼런스** — 다시 찾기 귀찮은 링크와 자료
- 🧩 **그 외 전부** — 어디에도 속하지 않는 모든 것

> 💬 한마디로, **"버리긴 아깝고 따로 두긴 애매한"** 것들의 집

---

## 🗂️ 구성

```
etc_kb/
├── README.md      # 지금 보고 있는 문서
└── ...            # 주제별로 자유롭게 추가
```

> 폴더 구조는 내용이 쌓이는 대로 자연스럽게 정리해 나갑니다. 처음부터 완벽한 분류를 강요하지 않습니다.

---

## 🧭 사용 원칙

1. **일단 적는다** — 완벽하게 정리하려다 아무것도 안 남기는 것보다 낫다.
2. **검색 가능하게** — 나중의 내가 키워드로 찾을 수 있도록 제목과 태그를 신경 쓴다.
3. **부담 없이** — 형식과 분량에 구애받지 않는다. 한 줄이어도 좋다.
