# 📖 wiki 폴더 안내

이 폴더의 파일들은 **GitHub 위키에 그대로 옮겨 넣기 위한 템플릿**입니다.

## 위키에 적용하는 법

1. 저장소의 **Wiki** 탭으로 이동합니다.
2. 각 파일의 내용을 복사해 같은 이름의 위키 페이지로 붙여넣습니다.
   - `Home.md` → 위키의 **Home** 페이지
   - `_Sidebar.md` → 사이드바 (특수 페이지)
   - `_Footer.md` → 푸터 (특수 페이지)
   - `Troubleshooting.md` / `Snippets.md` / `Notes.md` / `References.md` → 각 카테고리 페이지

> 💡 GitHub 위키에서 `[페이지이름](페이지이름)` 형식의 링크는 해당 위키 페이지로 자동 연결됩니다.
> 따라서 파일 안의 링크는 위키에 붙여넣으면 그대로 동작합니다.

## 파일 구성

| 파일 | 위키 페이지 | 역할 |
|------|-------------|------|
| `Home.md` | Home | 위키 대문 |
| `_Sidebar.md` | (사이드바) | 전체 페이지 네비게이션 |
| `_Footer.md` | (푸터) | 모든 페이지 하단 문구 |
| `Troubleshooting.md` | Troubleshooting | 에러·해결 기록 |
| `Snippets.md` | Snippets | 명령어·코드 조각 |
| `Notes.md` | Notes | 메모·아이디어 |
| `References.md` | References | 링크·자료 모음 |
